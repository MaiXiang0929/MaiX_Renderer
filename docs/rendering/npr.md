# 卡通光照、轮廓与面部阴影

NPR（非真实感渲染）由统一表面片段着色器的 Toon（卡通着色）分支和独立轮廓阶段组成。实现入口：[表面着色](../../assets/shaders/pbr/pbr.frag)、[轮廓阶段](../../src/Renderer/Passes/OutlinePass.cpp)、[轮廓顶点着色](../../assets/shaders/npr/outline.vert)、[材质参数](../../src/Renderer/Resources/Material.h)。

## 卡通分段光照

材质着色模型选择卡通后，片段阶段逐灯计算 `max(N·L,0)×attenuation`，用 `step(threshold,value)` 得到明暗分段。阴影颜色与白色根据阴影强度混合形成暗部，再通过光照分段在暗部与亮部之间选择。

灯光辐射值仍乘距离/锥体衰减与阴影可见度。当前衰减同时参与分段判断和光强，所以阈值边界可能随灯光距离变化；这不是只由表面法线决定的固定色阶。卡通分支不执行物理微表面镜面公式，也不使用 ORM（遮蔽、粗糙度、金属度）组合计算。

Rim Light（边缘光）使用 `pow(1-max(N·V,0),3)×strength`，乘艺术家指定颜色后加到结果。它依赖观察方向，是风格化加色项，不是灯光遮挡后的物理轮廓照明。

## 面部阴影的输入约定

Face Shadow（面部阴影）读取线性 SDF（有符号距离场；本实现实际消费连续阈值值）贴图红通道，并使用角色局部前向和右向。CPU（中央处理器）先合法化坐标轴，顶点或细分阶段将轴变到观察空间并正交化。

GPU（图形处理器）仅对 `keyLightIndex`（主光下标）对应灯使用面部结果：

1. 将表面到光的方向投影到面部右向、前向，得到二维方向。
2. 按右向分量符号选择是否镜像 U，额外镜像开关可反转约定。
3. 用 `abs(atan(right,forward))/π` 得到 `[0,1]` 光线角度阈值。
4. 采样面部贴图红通道，用角度附近的 `smoothstep`（平滑阈值函数）生成明暗。
5. 用此结果替换该主光的卡通分段，再乘原有阴影可见度与灯光强度。

投影方向退化时返回无效结果，回退到普通卡通分段。贴图不是直接作为脸部颜色，也不会替代几何投影阴影。普通、实例化、细分路径最终都输出相同的面部轴与片段接口。

## 目标资产与操作

```text
MaiX_Renderer.exe --face-shadow-demo "角色.fbx" "面部阈值.png" "精确材质名称"
```

启动入口先导入外部 FBX（模型交换格式），按材质名称定位目标，将面部纹理按线性数据上传并配置卡通/面部参数。外部角色资产不随仓库分发。应使用连续变化的阈值图，不能将普通色图、离散阴影色阶或高光贴图当作该输入。

检查步骤：选中脸部材质，移动主灯到正面、侧面和背面，检查左右镜像、角色旋转后轴向一致性，并调节过渡宽度。当前目标角色演示的视觉状态为待用户验收。

## 反向外壳轮廓

OutlinePass（轮廓阶段）只遍历主视图不透明卡通材质，要求轮廓开关与厚度有效。Inverted Hull（反向外壳）方法在观察空间沿变换后的法线扩张顶点，剔除正面、绘制背面，使用前向深度测试但不写深度，颜色写入已有高动态范围场景附件。

输入属性只有位置与法线，统一变量包括观察矩阵、法线矩阵、投影、厚度和颜色。厚度是观察空间长度，随距离改变屏幕像素宽度，不是恒定像素描边。法线接缝可能造成轮廓断裂，拓扑和法线质量影响最终效果。

## 资源、成本与边界

轮廓阶段拥有独立着色器，无独立场景颜色目标；扩张几何增加一次绘制和像素覆盖。面部阴影增加一次阈值纹理采样与方向角运算。参数由材质编辑器实时修改，实例可以覆盖相关参数，着色模型本身继承父材质。

轮廓当前不覆盖反射、透明或实例绘制；全局细分开启时直接跳过，以避免基础网格外壳与位移几何不匹配。头发高光、分离阴影色阶、专用角色渲染管线均未实现。

运行材质场景，将基础材质切换卡通，检查阈值、阴影颜色、边缘光与轮廓；按 F6 重载着色器并检查日志。初始化与数值约束可自动检查，风格效果由用户验收。
