# 场景代理、视图、裁剪与排序

## 负责系统与数据流

实现入口：[RenderScene](../../src/Renderer/Scene/RenderScene.cpp)、[RenderView](../../src/Renderer/View/RenderView.h)、[RenderItem](../../src/Renderer/View/RenderItem.h)、[批次构建](../../src/Renderer/View/RenderBatch.cpp)。

```text
可编辑模型根变换 × 分段局部变换
    → Renderer 更新图元的世界变换
    → RenderScene 保存图元代理
    → 每个 RenderView 独立裁剪与分类
    → 不透明资源排序 / 透明深度排序
    → 不透明批次 → 各绘制阶段
```

图元代理保存网格与材质的非拥有指针、稳定排序编号、局部包围球、世界变换、可见标记与投影标记。材质混合模式在代理中缓存，父材质修改混合模式时，Renderer 同步父材质及子实例对应图元的队列属性。

`BuildRenderView()` 清空并重新填充列表；不可见、缺资源的图元直接跳过，随后执行包围球裁剪。透明与不透明图元分别进入队列。灯光列表复制到视图，不执行灯光空间裁剪。

## 三个视图

| 视图 | 视图投影矩阵 | 用途 |
| --- | --- | --- |
| 主视图 | 相机投影 × 相机观察 | 前向、不透明轮廓和透明绘制 |
| 反射视图 | 相机投影 × 镜像观察 | 半分辨率反射目标，独立透明排序 |
| 阴影视图 | 灯光投影 × 灯光观察 | 阴影投射物裁剪，深度绘制 |

这些列表在 `Renderer::ExecutePipeline()` 栈上创建，管线同步使用。它们不是跨帧缓存，不能在异步任务中保留其中的裸指针。

## 世界包围球

[TransformBounds](../../src/Renderer/Scene/PrimitiveSceneProxy.cpp) 将局部球心乘世界矩阵，球半径乘矩阵三个基向量长度的最大值：

```text
世界球心 = M × (局部球心, 1)
世界半径 = 局部半径 × max(|M 的第一列|, |M 的第二列|, |M 的第三列|)
```

对于当前旋转、平移、正尺度缩放构成的变换，该方法能保守包住非均匀缩放对象。若未来引入任意剪切矩阵，最大列长度不能普遍保证保守，应重新评估包围体公式。细长物体的包围球可能保留实际不可见对象，影响效率而非当前变换路径的裁剪正确性。

## 视锥裁剪的数学

[Frustum](../../src/Renderer/View/Frustum.cpp) 根据 OpenGL 裁剪空间约束 `-w ≤ x,y,z ≤ w`，从视图投影矩阵取第四行分别加减前三行得到六个平面，再归一化法线与平面常数。矩阵按列存储，提取的是数学上的行，不能直接把连续内存当作行。

对平面 `n·x+d=0`，球心有符号距离为 `s=n·center+d`。任一平面满足 `s < -radius`，整个球在视锥外。相交球保留。无效平面、非正或非有限半径采取保留策略，避免因为缺少有效边界误删绘制。

CPU（中央处理器）执行这些测试，GPU（图形处理器）只收到保留的绘制项；这不是 GPU 遮挡裁剪，也不判断物体是否被其他物体挡住。

## 排序与批次

主视图与反射视图不透明项按着色器、材质、网格、图元编号排序。阴影视图按着色器、网格、材质、图元编号排序，强调深度绘制中网格的相邻性。使用稳定排序，编号提供确定的顺序。

透明项取世界包围球中心在观察空间的 Z 值。在 OpenGL 相机朝向负 Z 的约定下，Z 更小表示更远，升序绘制得到从后向前的顺序；相等深度保留提交顺序。阴影视图不排序透明项，阴影阶段只消费不透明列表。

`BuildOpaqueRenderBatches()` 将连续且着色器/材质/网格编号全部相同的项合并为范围。排序减少切换，批次允许实例绘制，两者不是同一个操作。不同材质的实例仍拆开；阴影阶段也仍使用包含材质身份的批次判定。

## 统计、验证与限制

`sourcePrimitiveCount` 是代理总数；`visiblePrimitiveCount` 是通过过滤进入队列的数量；`culledPrimitiveCount` 只统计视锥拒绝数量，因此三者不是简单相减关系。视图的 `opaqueDrawCount` 是不透明绘制项数，实际实例化后的绘制调用数应查看阶段提交统计。

[FrustumTests](../../tests/Renderer/View/FrustumTests.cpp) 验证平面与球体；[RenderSceneTests](../../tests/Renderer/Scene/RenderSceneTests.cpp) 验证分类、排序及共享引用；[RenderBatchTests](../../tests/Renderer/View/RenderBatchTests.cpp) 验证批次边界。运行 `--instance-grid 16` 可观察共享资源与批次，转动相机检查可见数变化。视觉效果待用户验收。

当前没有距离裁剪、遮挡裁剪、空间树或跨帧视图复用。透明中心排序不能解决相交网格和网格内部三角形顺序。
