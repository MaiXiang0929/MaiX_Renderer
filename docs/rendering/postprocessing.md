# 高动态范围与后处理

实现入口：[遮蔽阶段](../../src/Renderer/Passes/SSAOPass.cpp)、[光晕阶段](../../src/Renderer/Passes/BloomPass.cpp)、[后处理阶段](../../src/Renderer/Passes/PostProcessPass.cpp)、[后处理着色器](../../assets/shaders/postprocess/postprocess.frag)。

## 颜色链路

```text
前向 + 轮廓 + 透明：线性 HDR 场景颜色
    → 可选 SSAO 合成：线性 HDR 颜色
    → 可选 Bloom 提取与模糊
    → 场景颜色 + 光晕强度 × 光晕
    → 手动曝光
    → 色调映射或截断
    → sRGB 编码
    → 显示域编辑叠加合成
    → 最终视口纹理
```

HDR（高动态范围）场景目标是 RGBA16F（四通道 16 位浮点）。CPU（中央处理器）设置目标、投影逆矩阵与参数；GPU（图形处理器）通过全屏三角形组成的四边形执行图像采样和逐像素运算。禁用遮蔽时光晕和后处理直接读取原场景颜色，启用后读取遮蔽合成颜色，契约明确这一选择。

## 屏幕空间环境遮蔽

SSAO（屏幕空间环境遮蔽）利用前向可采样深度，无单独法线缓冲。深度与纹理坐标组成裁剪空间坐标，乘逆投影再除以 W 重建观察空间位置。相邻深度点重建的位置差叉乘得到法线，按朝相机方向修正符号。

原始遮蔽在半分辨率 R8（单通道 8 位）目标中计算。固定八个屏幕方向，偏移距离为深度纹素大小的八倍；重建采样位置后，根据观察空间距离、法线朝向、深度偏移和范围权重累积遮蔽。参数 `sampleRadius` 控制观察空间距离筛选，不直接改变屏幕采样核大小。

滤波用 3×3 邻域，依据原始深度差是否小于 0.01 决定权重，减少轮廓附近跨表面混合。随后在全分辨率 RGBA16F 目标上执行：

```text
遮蔽量 = clamp((1-AO) × intensity,0,1)
合成颜色 = 场景颜色 × (1-遮蔽量)
```

这里 AO（环境遮蔽值）作用于整个场景颜色，包括直接光、卡通和透明合成结果，并未分离间接光。透明不写深度，不能产生自己的深度遮蔽结构。固定核、非线性深度阈值和深度重建法线会在边缘带来局限；没有时域积累或更高级遮蔽算法。

## 光晕提取和模糊

Bloom（高亮光晕）在半分辨率 RGBA16F 上工作。先取颜色最大通道作为亮度指标，贡献为 `max(brightness-threshold,0)/max(brightness,ε)`，保留超出阈值部分。它不是按感知亮度加权的亮度公式。

然后使用两个目标交替执行八次模糊，水平/垂直各四次；每一步采样前一步结果，避免读取正在写入的同一附件。内部 Ping/Pong（交替双缓冲）由光晕阶段持有，最终模糊目标才作为跨阶段输出发布。

后处理阶段叠加光晕，不在提取阶段修改主场景颜色。阈值作用于曝光之前的颜色；修改曝光不会重新定义哪些像素进入提取。主要成本是九次半分辨率全屏绘制和纹理带宽。

## 曝光、色调映射与输出

手动曝光补偿以 `exp2(EV)` 缩放颜色，EV（曝光值）增加 1 意味着乘 2。没有亮度统计、适应速度或自动曝光。

开启色调映射时使用 ACES（学院色彩编码系统）风格拟合曲线：

```text
clamp((x×(2.51×x+0.03))/(x×(2.43×x+0.59)+0.14),0,1)
```

这是简化拟合，不是完整色彩管理流程。关闭时将曝光后颜色截断到 `[0,1]`。最后通过分段线性/幂函数转 sRGB（标准红绿蓝颜色空间）编码，写入 RGBA8（四通道 8 位）后处理纹理；应避免显示路径再次对同一结果编码。

## 编辑器叠加层

EditorPrimitivePass（编辑图元阶段）拥有全分辨率独立 RGBA8 目标。灯光图标和聚光锥在关闭深度测试状态下绘制，输出预乘透明度颜色，使用 `ONE / ONE_MINUS_SRC_ALPHA` 混合。方向光不画位置图标。即使叠加关闭，也清空并发布透明目标。

PresentPass（最终合成阶段）使用 `overlay.rgb + scene.rgb×(1-overlay.a)` 写最终纹理。叠加不参与曝光、光晕和色调映射；当前是显示域合成，并非线性光照域的物理透明合成。ImGuizmo（变换操作工具）则由界面绘制，不属于这个 GPU 场景叠加目标。

## 验证

[PostProcessSettingsTests](../../tests/Renderer/Pipeline/PostProcessSettingsTests.cpp) 验证参数限制，帧缓冲测试验证真实附件。运行默认和材质场景，分别开关遮蔽、光晕、色调映射，修改曝光，调整视口大小。检查灯光图标不随曝光变化、光晕提取范围、遮蔽边缘和输出亮度；视觉效果待用户验收。

## 米制默认场景参数（2026-10-02）

Application 将内置茶壶 SSAO 初始观察空间半径设为 0.005 米、bias 为 0.00025 米，SSAO 仍默认关闭。通用 RenderSettings 默认值保留；可编辑半径下限降为 0.001 米，面板增加小数精度和对数调节，避免小尺度参数被限制或显示为零。GPU 算法和资源格式未改动。
