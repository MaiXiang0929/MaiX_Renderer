## 如何区分实现与验证

实现说明来自源码检查；自动测试只验证相应逻辑或图形资源行为。历史性能数据独立标记，原有用户验收状态不自动扩展到其他功能。本轮构建与启动结果见[验证记录](documentation-review.md)，视觉效果由用户验收。

## 查问题的入口

- 没有最终纹理、目标尺寸或资源错误：先看管线与资源生命周期。
- 物体不可见、排序异常：先看场景与视图，再看透明或实例路径。
- 材质不跟随、贴图无效：先看材质及实例，再看模型实际分段绑定。
- 导入缺纹理、坐标不符：先看导入中间数据、轴向和纹理搜索。
- 时间或绘制数难解释：先确认统计口径，再对照当前阶段捕获。

构建和运行入口见根目录 [README](../README.md)。
